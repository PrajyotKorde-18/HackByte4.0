# PromptBridge

PromptBridge is an intelligent LLM orchestration interface designed for precision understanding and optimization.

## 🚀 Key Features
- **Intent-Aware Hub**: Automatically detects topics, domains, and learner levels.
- **Precision Optimization**: Uses internal textual gradients to evolve prompts.
- **Session History**: Context-aware conversations that remember past intents.
- **Glassmorphism UI**: High-impact modern design built with React and Vite.

## 🛠️ Stack
- **Frontend**: React + Vite + Vanilla CSS
- **Backend**: FastAPI + Python
- **AI Engine**: Provided by Groq (Llama-3-70B)

## 📦 Getting Started

### Backend
```powershell
cd backend
.venv\Scripts\python main.py
```

### Frontend
```powershell
cd frontend
npm run dev
```
